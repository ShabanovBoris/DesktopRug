# Desktop Rug

Нативный ковёр для рабочего стола macOS с интерактивной физикой ткани и отрисовкой Metal. Поднимайте углы, складывайте ткань и накрывайте иконки Finder.

[English](README.md) · [Скачать](https://github.com/ShabanovBoris/DesktopRug/releases/latest) · [Участие в разработке](CONTRIBUTING.md) · [Лицензия MIT](LICENSE)

![Складка ткани, отрисованная приложением](docs/images/cloth-corner.png)

## Возможности

- Прозрачная панель над иконками Finder и ниже обычных окон.
- XPBD: растяжение, сдвиг, изгиб, гравитация, трение, демпфирование и самоколлизии.
- Metal: освещение, контактные тени, толщина кромки и геометрическая бахрома.
- Четыре варианта: Heriz, Isfahan, «Советский · Красный» и «Советский · Цветочный».
- Столкновения с иконками Finder или явно добавленными ручными объёмами.
- Размеры, качество сетки, 30/60/120 FPS, блокировка, сохранение положения и автозапуск.
- После оседания ткани физика и отрисовка приостанавливаются.

Swift, AppKit, SwiftUI и Metal; внешних runtime-зависимостей нет.

## Установка

Скачайте ZIP из [GitHub Releases](https://github.com/ShabanovBoris/DesktopRug/releases/latest), распакуйте и перенесите **Desktop Rug.app** в Applications. После запуска ищите значок в строке меню: Dock-иконка отключена.

Готовый первый релиз требует **macOS 14+ и Apple Silicon**. Архитектура указана в имени архива. Скрипт допускает сборку исходников на Intel, но проверенного Intel-билда в первом релизе нет.

Билд подписан локально, **без Developer ID и нотариализации**. Если macOS блокирует первый запуск, после попытки открытия разрешите его через **System Settings → Privacy & Security → Open Anyway**, если доверяете этой загрузке. [Инструкция Apple](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac). Можно также собрать приложение самостоятельно.

Проверка контрольной суммы в папке загрузки:

```bash
shasum -a 256 -c DesktopRug-v1.0.0-macOS-arm64.zip.sha256
```

## Управление

| Действие | Результат |
|---|---|
| Перетаскивание середины | Перемещение всего ковра |
| Перетаскивание угла | Подъём и складывание ткани |
| Option + перетаскивание | Захват любой точки |
| Shift + нажатие | Добавление ручного объёма |
| Правый клик / Reveal Desktop Items | Скрытие ковра и доступ к файлам |
| Lock Rug | Пропуск мыши через ковёр |
| Relax Fabric | Разглаживание сетки над текущими объектами |
| Reset Rug Position | Возврат в центр выбранного дисплея |

В **Settings → Appearance** выберите рисунок. Вкладка **Cloth & Motion** управляет физикой, **Desktop** — дисплеем, Finder, ручными объёмами и автозапуском.

## Finder и данные

Нажмите **Connect Finder…** и разрешите Automation для Desktop Rug → Finder. Приложение читает имена, URL, размер и позиции desktop-иконок через публичный AppleScript-интерфейс. Оно не перемещает, не редактирует и не удаляет файлы. Accessibility и Screen Recording не требуются.

Опрос выполняется раз в две секунды при видимом ковре. При ошибке останавливается с сообщением в настройках. Автоматическая геометрия поддержана на основном дисплее с обычным расположением иконок. Stacks, сортировка и дополнительные дисплеи могут возвращать недоступные или устаревшие позиции; доступны ручные объёмы.

Телеметрии и сетевого клиента нет. [Сведения о локальных данных](docs/PRIVACY.md).

## Сборка

Нужны macOS, Apple Swift compiler с macOS SDK и Python 3.9+. Python-пакеты не требуются.

```bash
git clone https://github.com/ShabanovBoris/DesktopRug.git
cd DesktopRug
python3 scripts/build.py
open "build/Desktop Rug.app"
```

Скрипт собирает оптимизированное приложение для архитектуры текущего Mac, включает текстуры, лицензию и применяет локальную подпись с Apple Events entitlement. При отсутствии готовой Metal-библиотеки включённый исходник компилируется системой при запуске.

Альтернатива: откройте **DesktopRug.xcodeproj**, схему **DesktopRug**, и запустите Release. Для этого нужна полная установка Xcode с его компонентами.

Версия хранится в `VERSION`. После её изменения или добавления исходников/ресурсов пересоздайте проект:

```bash
python3 scripts/generate_project.py
```

## Проверки и упаковка

```bash
bash scripts/test.sh
python3 scripts/package_release.py
```

14 XCTest проверяют геометрию, столкновения, самоконтакт, захват, оседание, устойчивость, координаты и сохранение конфигурации. CI выполняет тесты, сборку и проверку архива. Скрипт упаковки требует предварительной сборки; проверяет версию, архитектуру, подпись, права исполняемого файла и содержимое после распаковки. Результат — ZIP и SHA-256 в `build/release/`.

Нативные проверки требуют графической сессии. Сначала закройте обычное приложение:

```bash
"build/Desktop Rug.app/Contents/MacOS/DesktopRug" --validate "$PWD/build/validation" --deep-fold
"build/Desktop Rug.app/Contents/MacOS/DesktopRug" --validate-ui "$PWD/build/ui-validation"
```

Они используют изолированные настройки и тестовую геометрию, сохраняют только собственные Metal-кадры и SwiftUI-представления. [Подробности проверок](docs/TESTING.md).

## Ограничения

Один ковёр на выбранном дисплее. Перенос между дисплеями выполняется через настройки. Полная проверка Spaces, Mission Control, Stage Manager и fullscreen не проведена. Изгиб и самоколлизии приближённые: при экстремальном смятии разделение слоёв не гарантировано. Ткань может сохранять складки; для разглаживания есть Relax Fabric.

Толщина иконок моделируется, тени приближённые. Около 60 FPS измерены в коротком локальном прогоне; результат зависит от машины и качества сетки. Длительный тест утечек не завершён. Положение и настройки сохраняются, деформированная сетка при запуске рассчитывается заново.

## Лицензия и графика

[MIT](LICENSE). Heriz/Isfahan и иконка генерируются `Tools/GenerateRugAssets.swift`. Советские текстуры подготовлены imagegen по предоставленным фотографиям; [происхождение и запросы](DesktopRug/Resources/TextureSources.md) сохранены. Исходные фотографии не включены в репозиторий. Изображения документации содержат только собственный рендер и настройки приложения.

```bash
swift Tools/GenerateRugAssets.swift DesktopRug/Resources
```

Генератор не перезаписывает советские текстуры. Описание архитектуры находится в [английском README](README.md#architecture).
