# Changelog

## 1.0.0 — 2026-10-11

Initial open-source release.

- Native AppKit desktop panel, SwiftUI settings, and Metal renderer.
- Interactive XPBD cloth with self-contact, corner lifting, arbitrary point grabbing, friction, and settling.
- Heriz, Isfahan, Soviet Red, and Soviet Floral rug patterns.
- Optional public Finder integration and manual collision mounds.
- Menu bar visibility/lock controls, saved configuration and position, display selection, and login item support.
- Three mesh qualities, adjustable material settings, and 30/60/120 FPS limits.
- Fourteen physics/configuration tests and native rendering/UI diagnostics.
- Reproducible project generation, release archive verification, SHA-256 files, and macOS CI.

The downloadable binary targets Apple Silicon and macOS 14+. It is ad-hoc signed and not notarized. Intel runtime, all desktop-window transitions, and extended leak testing have not been fully verified.
